Online Quiz Application
Project Description
Online Quiz Application is a simple quiz project developed using Java, HTML, and CSS. It allows users to answer multiple-choice questions and view their quiz score.

Features
Multiple-choice questions
Easy-to-use interface
Answer selection
Score calculation
Final result display
Try again option
Technologies Used
Java
HTML
CSS

└── README.md
How to Run
HTML and CSS
Download or clone the project.
Open index.html in a web browser.
Click on the Start Quiz button.
Answer the questions.
Click Submit Quiz to view the result.
Java
Compile the Java program:

javac Quiz.java
Run the program:

java Quiz
Sample Quiz
The application contains Java-related questions such as:

Which keyword is used to create a class in Java?
Which method is the starting point of a Java program?
Which data type is used to store whole numbers?
Which keyword is used to inherit a class?
